# Tapilot 導入手順（初心者向け）

## 用意するもの
- iPhone（iOS 17.4 以降）とUSBケーブル
- Windows PC（初回の1回だけ使います）
- Apple ID（無料で可。有料の開発者登録は不要）
- Gemini の APIキー（無料枠。https://aistudio.google.com/apikey で作成）

## 1. PCでの作業（約10分）
1. PCセットアップツール（iloader 改造版）をインストールして起動する
2. iPhone を USB でつなぎ、iPhone に「このコンピュータを信頼しますか？」と出たら「信頼」
3. ツールで Apple ID にサインインし、デバイス一覧から iPhone を選ぶ
4. 「**Tapilotをセットアップ**」を押す
   - SideStore・Tapilot・WebDriverAgent の取得と導入、認証ファイルの配置、開発者モードの項目の表示までを自動で行います
   - 「証明書の上限」などの質問が出たら、押す前に内容を確認（分からなければ中止）
5. 「PCでのセットアップが完了しました」と出たら、ケーブルを外してよい

## 2. iPhoneでの作業（約10分）
1. 開発者モード：設定 → プライバシーとセキュリティ → デベロッパモードをオン → 再起動
2. 信頼：設定 → 一般 → VPNとデバイス管理 → 自分のApple ID →「信頼」（「検証済み」なら不要）
3. App Store から「LocalDevVPN」を入れて接続
4. SideStore を開き、Apple ID でサインイン
   - **「Revoke」（証明書の取り消し）の画面が出ても押さない。Cancel を押す**（押すと全部のアプリが起動しなくなります）
5. SideStore の「＋」→「このiPhone内」→「Tapilot」→「SideStore用」→ Tapilot.ipa、続けて WebDriverAgent-tapilot.ipa を選ぶ
   - これで 7日ごとの更新を SideStore（iPhoneだけ）で行えるようになります
6. Tapilot を開き、「はじめに」の6項目を上から順に ✅ にする（APIキーの貼り付け、操作するアプリの選択など）

## 3. 7日ごとの更新
- LocalDevVPN を接続して SideStore の「Refresh All」。Background Refresh をオンにしておくと自動でも更新されます
- 期限は Tapilot の「はじめに」と SideStore の「My Apps」に表示されます

## 注意
- 無料 Apple ID で同時に使えるアプリは3個まで（SideStore・Tapilot・WDA で上限）
- 課金・購入・設定変更の画面では AI は操作しません
- iPhone を再起動したら、LocalDevVPN を接続してから Tapilot を開いてください（開発用の部品は Tapilot が自動で準備します）
